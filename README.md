# 海边慢时光 · 网页触控体验

这是基于电脑上现有中文游戏资源制作的独立网页体验。它不会安装到 C 盘，也不会改动原来的桌面版。开源原项目已下载到 `E:\aaa\tidewater-source`，供后续继续开发。

## 在这台电脑上预览

双击 `启动网页体验.cmd`，浏览器会打开 `http://127.0.0.1:5189/`。首次打开需要编译大量画面效果，可能要等待一段时间。请保持命令窗口打开；关闭窗口即停止本地网页服务。电脑浏览器上想预览触屏按钮，可打开 `http://127.0.0.1:5189/?touch=1`。

## 平板操作

- 左下摇杆：移动；右侧空白区域：滑动视角。
- 右下：互动、拿鱼竿、跳跃、加速、按住抛竿或收线。
- 右上：背包、设置、画质、更多。更多里有下潜、切换船上视角、手电和收回空线。
- 竖屏也能显示；横屏视野更大。触控设备默认使用较低画质，可在画质按钮切换。

## 平板打开方式

目前交付的是 E 盘上的**本地体验**。平板无法直接使用电脑的 `127.0.0.1` 地址；发布到 HTTPS 网页地址后，Android 和 iPad 可在浏览器打开，并可通过浏览器菜单添加到主屏幕，无需应用商店。发布前还需要确认公开范围和托管位置。游戏要求设备与浏览器支持 WebGPU，屏幕适配无法替代这个硬件要求。

网页存档保存在浏览器中，与原桌面版存档分开。动态壁纸尚未制作，后续可基于同一套画面资源开发。
